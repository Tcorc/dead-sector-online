DEAD SECTOR WEB CINEMA

This is an original abandoned-cinema map inspired by the atmosphere and flow of classic theater zombie maps.
It is not a 1:1 recreation of Kino der Toten.

NEW / REBUILT:
- Much larger 88 x 76 theater environment.
- Foyer / spawn room.
- Large auditorium.
- Raised stage with red curtains.
- Backstage / dressing corridors.
- Left and right side halls.
- Balcony / projector overlook.
- Visible staircases on both sides of auditorium.
- Rows of theater seats.
- Warm broken theater lighting.
- Seven true zombie window openings.
- Wooden barricade visuals at windows; zombie path is not blocked by the decorative slats.
- Zombie spawn points line up with those windows.
- A* pathfinding remains active, so zombies route through open doors and window gaps.
- Door opening forces immediate zombie repath.
- Purchase system remains server-authoritative with success / denial messages.
- Perks, doors, Mystery Box, wall buys, ammo, and 3 weapon upgrade levels retained.

DEPLOY:
Upload the entire DeadSectorWeb_Cinema folder to GitHub.
Render Root Directory: DeadSectorWeb_Cinema
Build Command: npm install
Start Command: npm start
