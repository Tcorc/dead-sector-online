DEAD SECTOR WEB V9 - PRE-GAME LOBBY

NEW:
- Creating/joining a room now places everyone in a PRE-GAME LOBBY.
- No zombies spawn while you are waiting.
- Lobby shows:
  * Room code
  * Player count (up to 4)
  * Player names
  * Which player is host
- COPY INVITE LINK button is available in the lobby.
- Only the host sees START MATCH.
- The host can wait until friends join, then start the game.
- Starting the match resets everyone and begins the Round 1 countdown.
- Game Over -> Return to Lobby brings the whole group back to this waiting room.
- Host migration still works if the host disconnects.

MOBILE:
- Mobile friends can join the same lobby from Safari/Chrome.
- Touch controls appear once the match starts.

PC / XBOX / MOBILE controls and all V8 gameplay features remain.

START:
Extract the ZIP and double-click START_GAME.bat.

SAME WIFI:
Host creates room -> COPY INVITE LINK -> send link -> friend opens link -> friend joins lobby.

DIFFERENT HOUSES:
The server still needs to be hosted publicly on a Node/WebSocket host for internet-wide joining.
