DEAD SECTOR V10 - ONLINE READY

This package is configured for a public Node.js web service with Socket.IO/WebSockets.

RECOMMENDED: RENDER

1. Create a GitHub repository named dead-sector-online.
2. Upload the CONTENTS of this folder to the repository root.
   package.json, server.js, render.yaml and the public folder must be at the top level.
3. On Render choose New -> Web Service.
4. Connect the dead-sector-online GitHub repository.
5. Settings:
   Runtime: Node
   Build Command: npm install
   Start Command: npm start
6. Create the Web Service.
7. When deployment finishes, open the HTTPS onrender.com address.
8. Create a room.
9. In the pre-game lobby press COPY INVITE LINK.
10. Send that HTTPS link to friends anywhere. They open it in a browser and join your room.

IMPORTANT:
- You do NOT run START_GAME.bat when using the online hosted version.
- Keep the Render service to one instance because lobby/game state is currently held in server memory.
- A free service may need time to wake after inactivity.
- Deploying/restarting the service clears active rooms because match state is in memory.
